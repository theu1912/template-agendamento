# Instruções permanentes para este projeto

Antes de começar qualquer tarefa, leia os arquivos em
`C:/Users/Matheus/Desktop/Segundo-Cerebro/projetos/barbershop-template/`
(`barbershop-template.md` = log/histórico do projeto; `barbershop-template-stack.md` =
regras técnicas fixas). Siga rigorosamente as regras de arquitetura descritas em
`barbershop-template-stack.md`.

Ao final de TODA sessão de trabalho neste projeto, sem exceção, atualize
`C:/Users/Matheus/Desktop/Segundo-Cerebro/projetos/barbershop-template/barbershop-template.md`
com uma nova seção descrevendo:
- O que foi feito nesta sessão
- Decisões de escopo tomadas (o que foi incluído/excluído e por quê)
- Achados fora do escopo pedido (bugs, dívidas técnicas, inconsistências
  encontradas mas não corrigidas)
- Pendências que ficaram em aberto para a próxima sessão

Siga o mesmo estilo das seções já existentes no arquivo (títulos com data e
origem da sessão, bullets objetivos). Isso vale mesmo que a tarefa pedida
não mencione explicitamente "atualize o log" — é uma instrução permanente,
não algo a ser repetido a cada prompt. O usuário e outras sessões de IA
dependem desse arquivo para entender o estado real do projeto sem precisar
reler todo o código-fonte a cada vez.
